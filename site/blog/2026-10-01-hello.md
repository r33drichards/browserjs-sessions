# A Linux desktop for your agent

*1 October 2026*

An agent that uses a computer needs a computer to use. Lending it your own
laptop means lending it your files and your accounts, and keeping the lid
open. A fresh headless browser per task forgets every login, and you cannot
see what happens in it.

browserjs sessions sit between the two. A session is a small Linux desktop
in the cloud, with Chromium open on it:

- **The agent operates it over MCP.** Every session has its own endpoint.
  Add it to Claude or another MCP client. The agent writes JavaScript with
  `run_js`, and that code drives the browser.
- **You watch, and take over.** The desktop is on your screen, in the page.
  Sign in to a site yourself, solve the captcha, then hand back.
- **It remembers.** The disk persists, so logins and tabs are there next
  time. An idle session sleeps; the next call wakes it with the screen as it
  was.
- **It is isolated.** One sandbox, one disk and one endpoint per session.
  Use one per task or per client, and delete it afterwards.

## What it is not, yet

The desktop is minimal: a display, a window manager and Chromium. There is
no terminal and no other application.

The agent acts on web pages today. Using the mouse and keyboard on the whole
desktop is planned. Policies per session, API tokens and a Terraform
provider are built and not enabled yet. The
[status page](/reference/status) says what is live.

## Try it

Sign in at [app.computeruse.site](https://app.computeruse.site) with Google
or GitHub, choose **Create session**, and follow
[Your first desktop](/tutorials/first-session).
