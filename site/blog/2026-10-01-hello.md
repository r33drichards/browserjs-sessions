# Serverless, resumable desktop containers

*1 October 2026*

::: info Update: 3 October 2026
Policies are now live for new sessions, and API tokens are enabled. The
desktop now includes XFCE, a terminal and a file manager, and agents can run
programs with `exec`. The launch description below records the state on
October 1; see [Live, coming and planned](/reference/status) for current
availability and [Write a policy](/guides/write-a-policy) for older sessions.
:::

The idea is small: simple, stateful desktop containers with a code-mode MCP
tool, that scale to zero.

**Simple.** A session is a desktop container. You create it with one click
and get one MCP URL.

**Stateful.** It is a real desktop on a persistent disk. Going to sleep
takes a snapshot. Waking restores the screen and its processes as they were.

**Scale to zero.** A session sleeps when idle and uses no compute. The next
MCP call wakes it.

**Code mode MCP.** The agent gets one tool, `run_js`. It writes a program
that operates the desktop, in the browser by selector or on the screen with
mouse and keyboard, and returns only what matters.

**A light admin interface.** List, create, watch and take over, stop,
delete.

**Policy to contain it.** Each session can carry a policy that decides
which of the agent's calls are allowed. This is built and not switched on
yet.

## What is there today

The desktop is minimal: a display, a window manager and Chromium. A fuller
desktop with a terminal, and a shell capability for code, are planned. The
[status page](/reference/status) lists what is live.
