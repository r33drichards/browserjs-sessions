# Move files and the clipboard

Your computer and the desktop are separate machines. Two boxes under the
screen connect them.

## Send text to the desktop

1. Choose **Send my clipboard**, or paste text into the Clipboard box and
   choose **Send to browser**.
2. Click where it should go on the desktop and press `Ctrl+V`.

## Get text from the desktop

1. Copy it on the desktop with `Ctrl+C`. It appears in the Clipboard box.
2. Choose **Copy**.

The desktop runs Linux: its shortcuts use `Ctrl`, also when you are on a
Mac.

## Send a file to the desktop

Drop the file anywhere on the session's page, or choose **Send files to
browser**. You can also click the Files box and paste a copied file or
screenshot.

The file lands in the desktop's Downloads folder and is listed in the Files
box. It is also put on the desktop's clipboard, so `Ctrl+V` in a page that
accepts pasted files attaches it. Or use the site's upload button: the file
chooser opens in the Downloads folder.

A file is never replaced. A taken name becomes `report (1).pdf`.

## Get a file from the desktop

Download it in the desktop's browser. It appears in the Files box. Choose
**Save**.

## Delete a file

Choose **Delete** next to it and confirm.

## Limits

100 MB a file. Files only, not folders. The folder shares the session's
5 GB disk. See [Limits](/reference/limits).
