# Create, stop, resume and delete sessions

## Create

1. On the **Sessions** list, choose **Create session**.
2. Type a name, or leave it empty to use the suggested one.
3. Choose **Create**.

A name is 1 to 63 characters. Names need not be unique. You can have up to
five sessions; see [Limits](/reference/limits).

A new session usually takes a desktop that is already running, so it is
ready in seconds.

## Rename

On the session's page, choose **rename** next to the name, type the new one,
and choose **Save**. The MCP URL does not change.

## Stop

Choose **Stop**, on the list or on the session's page. The desktop shuts
down and the disk is kept.

A stopped session stays stopped. An agent's call does not start it; see
[Session states](/reference/session-states).

## Resume

Choose **Resume**. The desktop starts from the disk and Chromium reopens its
tabs.

## Delete

Choose **Delete** and confirm. The session and its disk are removed. This
cannot be undone. The MCP URL stops working.
