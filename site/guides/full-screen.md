# Full screen and resize

## Full screen

Choose **Full screen** at the top of the session's page. To leave, press
`Esc`.

The button is missing where the browser you are using cannot do full screen,
such as on an iPhone.

## Resize

The desktop follows the size of the screen box. Make your window larger or
smaller, or go full screen, and the desktop takes the new size after a short
pause. Chromium's window stays maximised, so it follows too.

The desktop is at most 2560 by 1600. In a larger box the picture is scaled
up to fit.

The size changes only when a viewer asks. With no page open, the desktop
keeps the size it last had, which is also the size an agent sees.
