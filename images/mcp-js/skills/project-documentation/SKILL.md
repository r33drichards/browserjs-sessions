# Project documentation

Use this repository's bundled documentation to understand the project before
implementing or operating it. Read `INDEX.md` to select relevant pages, then
fetch only the supporting files needed for the task.

`references/docs/` contains the project's documentation, including contracts,
runbooks, and historical design plans. `references/site/` contains the published
reference pages. `references/README.md` is the project README.

Prefer the current runbooks and contracts over historical plans. Treat commands
and infrastructure settings as documented examples; verify the current
environment before applying them. This skill does not authorize deployment,
install packages, or grant execution permissions. Use the tools and permissions
already available in the session.
