Control the connected browser through browser_execute and the local desktop through desktop_execute, using mcp.callTool. JavaScript state is fresh on each run_js call; browser tabs persist. The browser must already be listening on CDP_URL (default http://127.0.0.1:9222). Desktop control requires the local platform's native dependencies and permissions. When an exec server is configured, use its exec, stream_logs, search_logs and kill tools. The gateway does not provide the hosted service's /data/memory filesystem or artifact-upload workflow.
